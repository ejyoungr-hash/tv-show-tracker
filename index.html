TV Show Tracker

Keep a list of the shows you watch, see what each show is about, and record the season and episode you are on. Show details and episode lists come from TVMaze.

Add a show

Search TVMaze by show name, then add a result to your list. Adding a show also loads its full episode list.

My shows

Your list is saved in this browser on this device only. Use the backup section below to move it or restore it after clearing browser data.

Backup and restore

Your list is stored only in this browser. Export a backup file before clearing browser data, then import it afterwards to get everything back.

JSON — full backup

Saves your whole list and progress exactly as it is. Importing a JSON file replaces the list on this device with the file's contents.

Import JSON

CSV — for Excel

One row per episode, with a watched column. Opens cleanly in Excel. On import, the file is checked first and any problem rows are listed before anything is applied.

Import CSV

CSV import adds or updates shows and watched marks from the file's valid rows. It does not delete shows that are already in your list.
